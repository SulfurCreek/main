# 改版紀錄（Merit）：求才端 User Journey Map HTML

目標：以 Awwwards／Webby／FWA 得獎水準為標準，自我檢查、反覆修正。共跑了 5 輪截圖審查（v0→v4），檢查範圍是 1440 亮色與暗色、390 手機版，以及選了階段之後的畫面。可重用的規則已整理進 `.claude/skills/report-generator/references/award-grade-checklist.md`。

## 改版前的問題（v0 自評）

| 問題 | 為什麼不到得獎水準 |
| :--- | :--- |
| 系統字體、無字體個性 | 看起來像預設文件，沒有視覺識別 |
| 第一屏是「先看這裡」的兩張表 | 第一屏沒有回答這頁到底在講什麼；旅程本身被推到第 3 屏 |
| 階段篩選是一排小 pill | 篩選器沒有承載任何意義，只是一排按鈕 |
| 頁長 8,800px（1440 寬） | 術語表、階段表、旅程看板互相重複 |
| 1440 寬看板要左右捲 294px | PC 看不完八個階段 |

## 逐項改動

| # | 改動 | 依據（可重用原則） |
| :--- | :--- | :--- |
| 1 | **Hero 用路線圖**：8 個階段畫成捷運路線，主線 J→5，6／7 是虛線「支線・任何階段可轉乘」 | Hero 要呈現題目本身最有代表性的東西；旅程就是一條路線，支線如實表達了「任何階段可插入」 |
| 2 | **路線圖本身就是篩選器**：站點＝階段按鈕，被選的站實心並跑一次脈衝，其他站變淡 | 控制元件要帶資訊，不要另外放一排按鈕 |
| 3 | 每站顯示白話名稱、新版／現版、這一階段在做什麼，以及「頁面 N・文件 N・流程圖 N」 | 用這個題目才有的真實單位（Sitemap 頁面數）當內容，不當裝飾 |
| 4 | 「階段讀法」表併入路線圖，不再重複出現 | 同一份資料只呈現一次；頁長降到約 6,100px |
| 5 | **捲動後出現的迷你路線列**（固定在頂部、毛玻璃）：離開 hero 之後仍能切換階段 | 篩選會影響全頁，所以控制元件要一直在手邊 |
| 6 | 字體三種角色：Noto Sans TC（中文）、Archivo 寬體（站碼／英文標題）、IBM Plex Mono（數字與檔名），全部有系統字體 fallback | 標題字有個性、內文字耐讀、資料字等寬；離線時照樣可讀 |
| 7 | 配色：鈷藍＝主線與互動，琥珀＝支線與 US*，綠＝機會點，灰階帶藍偏色；暗色版另外調，不是直接反相 | 一個重點色、語意色分開；兩個主題都要設計 |
| 8 | 段落標題統一為英文 eyebrow 加中文 h2（例如 CONTEXT／情境設定） | 重複出現的元素格式一致 |
| 9 | 情境區：Persona 卡（變體、場景、旅程類型）＋閱讀指南（標記圖例、版本規則、狀態標籤），術語改成全寬三欄定義表 | 卡片不要被旁邊高的欄位撐出大片空白（`align-items:start`） |
| 10 | 看板：列標欄 112px、欄最小 160px、外邊距 `clamp(16px,1.6vw,40px)` | 1440 寬八欄一次看完，不用左右捲 |
| 11 | Touchpoints：沒選階段時是緊密文字（以「・」分隔），選了才變成可點的錨點 chip | 狀態要反映在形式上；未選時不讓 chip 把列高撐到 600px |
| 12 | 英文列標用窄體、`word-break:keep-all` | 修掉 TOUCHPOI／NTS 斷字 |
| 13 | 支援欄 6／7 的站碼字級縮小、字距收緊 | 修掉兩字元站碼溢出圓圈 |
| 14 | 流程圖空狀態是點陣底的虛線框加一句行動指引；SVG 最寬 1180px | 空狀態也要設計；循序圖太寬會被拉得太高 |
| 15 | Sitemap：模組在 PC 排成兩欄，節點用捷運支線式的連接線；選了階段，對應模組的連接線與站碼變成鈷藍 | 和 hero 用同一套視覺語言 |
| 16 | 動態只有一個主要時刻：載入時路線畫出（0.9s），選站時脈衝；`prefers-reduced-motion` 時全部關閉 | 一個精心安排的動態，勝過到處都在動 |
| 17 | 手機版（860px 以下）路線改成直向，站點沿垂直線排列 | 在窄螢幕是重新排版，不只是縮小 |

## 驗證

- Playwright：1440 亮色與暗色、390 亮色；頁面沒有橫向捲動，JS 沒有錯誤。字體載入失敗只是沙盒 proxy 造成，不是頁面問題。
- 互動測試：
  - 進頁時流程圖 SVG 數為 0，選 C 後為 1。
  - 選 C 後亮起 1 個 Sitemap 模組，文件表剩 1 列。
  - 點 Touchpoints 的「職缺列印」會跳到並標亮 Sitemap 節點。
  - 迷你路線列：離開 hero 後出現，可以切換到 D，也可以切回全部。

## 還可以再進一步
