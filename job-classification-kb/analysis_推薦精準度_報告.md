### 最需優先改善的中類（n≥300，top1~10累積命中率最低）

1. **電腦硬體**（19.17%）— 61.66% 誤判到「同大類但錯中類」，主因是與「網路管理」「軟體工程」職稱字面重疊（如「MIS工程師」「網路工程師」易被歸到硬體或反之）。
2. **專案管理**（18.05%）— 31.34% 完全無關，常見「PM／專案經理」字面被行銷、產品企劃、甚至軟體工程搶走，跨領域職稱衝突嚴重。
3. **網路管理**（21.71%）— 49.57% 落在同大類其他中類（多半是電腦硬體/軟體工程），與電腦硬體同病。
4. **電子通訊 / 光電半導體**（25%／26.8%）— 37~38% 沾邊同中類，說明推薦方向對但排序差；此二中類職稱本身高度相似（工程師頭銜重複率高）。
5. **維修／技術服務**（25.5%）、**操作技術**（33.29%）— 高比例落在「同大類沾邊」，操作/維修/加工類職稱詞彙混雜、推薦難以精準分流到子類。

### 具體缺陷樣態與案例

**A. 完整徵才文案取代乾淨職稱（最大宗問題）**
標題夾帶店名、地址、薪資、班表、福利敘述，關鍵字被稀釋、甚至被文案中的產業詞(如「工廠」「智慧製程」)帶偏方向：
- `W【日班安全室組長】中壢工業區：工廠，薪62,000元/月上班24天(288H)，有供餐及特休` → 現有=保全人員／警衛，推薦卻給出「智慧製程工程師、電機技師／工程師」（完全無關）。廠區地址中的「工業區」「工廠」關鍵字蓋過了真正的職務詞「安全室組長」。
- `W【勤務督導】桃園區中正路，薪58,000~68,000元(含全勤及津貼)/週休二日、見紅休` → 現有=總幹事，推薦=「資材主管、智慧製程工程師」（無關）。
- **建議改善方向**：推薦前應先做「職稱淨化」——優先抽取括號外、無標點的核心詞組（尤其是句首或緊鄰班別/組別的功能詞），降低薪資/班表/地址片段的權重。

**B. 品牌／店名前綴掩蓋末段功能詞**
「function tail」規則本應保護末段職務詞，但當功能詞後方還接了時數/班別等雜訊時規則失效：
- `挪威森林(新店館)值班主任9H月休八天**` → 現有=飯店／旅館主管，推薦前三=「品管／品保主管、資材主管、店長／門市管理人員」（沾邊_大類，未命中「值班主任→旅館主管」的對應）。
- `Mr.Wish-儲備幹部(永康大武店)` → 現有=餐飲服務人員，推薦=「品管／品保主管、調酒師／吧台人員、資材主管」（沾邊_中類）。
- **建議改善方向**：function tail 抽取時應允許「功能詞 + 附加時數/班別文字」的模式（正則上功能詞不必是字串結尾，而是「最後一個有效中文詞組」），並優先剝離括號內品牌/分店名稱。

**C. 裝飾符號、表情符號、數字編號前綴弱化定位**
- `◎市議員助理◎` → 現有=行政助理，推薦=「電腦操作／資料輸入、行銷企劃助理、秘書」（沾邊_中類，未給出「議員助理」；但此職類本身**不在 tCodeDutyNM 617 葉之列**，屬代碼表收錄缺口而非純文字判斷問題，建議一併提報 `tcode/data_tCodeDutyNM_changes.md` 待議新增）。
- `遠傳📞電信儲備幹部【薪42000起+業績獎金】` → 現有=門市／店員／專櫃人員，推薦=「客服主管、儲備幹部、國外業務主管」（沾邊_大類）。emoji 未被有效過濾，且「電信」產業詞把推薦帶往客服/業務方向。
- `1.經營企劃專員` → 現有=產品管理師，推薦=「保險業務員／經紀人、產品企劃主管、國內業務主管」（沾邊_大類）。純數字編號前綴（常見於複製貼上的條列式職缺）稀釋了「經營企劃專員」的完整詞組匹配。
- **建議改善方向**：前處理階段先行剝除 emoji、項目符號（`◎★☆【】※`）、開頭編號（`^\d+[.、]`），再進入關鍵字比對。

**D. 極短通用職稱：問題可能出在「現有」而非「推薦」**
標題 ≤3 字（如「儲備幹部」「場務」「主任」）miss rate 最低（22.7%），但抽樣顯示不少案例是**推薦精確重現了字面職稱，反而是 duty0 現有標記與職稱字面不符**：
- `儲備幹部` → 現有=工務助理，推薦 top1=「儲備幹部」（字面完全吻合，但因與 duty0 不同被算作「無關」）。
- `主任` → 現有=飯店／旅館主管，推薦 top1=「儲備幹部」。
- **建議改善方向**：這類「推薦=標題字面本身」但判定為 miss 的案例，應反向稽核**「現有」欄位的標記品質**，不宜直接歸咎於推薦演算法；建議抽樣併入 `不合理清單_職類校正` 流程覆核。

**E. 高度相似職類彼此混淆（非文字前處理問題，屬職類體系本身的鄰近性）**
「電腦硬體 vs 網路管理 vs 軟體工程」「專案管理 vs 產品企劃 vs 行銷」「光電半導體 vs 電子通訊」等中類職稱字面高度重疊，即使標題乾淨也難以精準分流（見第三節「最需優先改善的中類」）。此類問題**不屬於文字雜訊**，需靠職類體系層級的消歧特徵（如公司產業別、學歷科系關聯）輔助，非單靠職稱文字可解。
