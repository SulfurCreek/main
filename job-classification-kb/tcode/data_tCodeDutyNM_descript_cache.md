# tCodeDutyNM Description 反查快取（葉節點職務說明）

> **用途**：判斷職缺名稱該歸哪個葉時，先反查葉節點的 `CodeDefinition`／`CodeDescript`／`CodeAlike`，
> 用「職務說明是否涵蓋職缺名稱的關鍵字職能」做裁決，不要只看葉名字面。
> **鐵則**：不可直接 `load_workbook` 讀 `TCode_Export.xlsx` 查值。缺哪個葉，就用
> [`skills/tcode-desc-lookup-skill.md`](../skills/tcode-desc-lookup-skill.md) 的抽取程序把該葉補進本檔，然後讀本檔。
> 本檔是**逐案累積**的快取：只收實際案件用過的葉，不是全表 dump（614 葉全文太大，違反 tabular-token-min）。
