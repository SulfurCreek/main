## 寄件者代碼 SendKind

訊息的寄件者與來源以 `SendKind` 標記（來源：`get-detail/{infoNo}` API）。同一則信件在收發兩端各有一筆對應紀錄，廠商端與求職端各自只顯示部分代碼，故每個訊息類型於兩端對應的 `SendKind` 不同，逐一列於以下各章節。

| SendKind | 說明 | 備註 |
| :---: | :--- | :--- |
| `0` | 廠商 | 廠商寄出信件（廠商端） |
| `1` | 求職者 | 求職者寄出信件（求職端） |
| `3` | 廠商系統訊息 | 廠商動作產生的訊息 |
| `4` | 求職者系統訊息 | 求職者動作產生的訊息 |
| `5` | 求才發給求職系統信 | `3` 動作產生的信件，顯示於求職端 |
| `6` | 求職給求才系統信 | `4` 動作產生的信件，顯示於求才端 |
| `7` | 求才回收 | 廠商回收訊息 |
| `8` | 求職回收 | 求職者回收訊息 |
| `9` | 求才即時通 | 即時通廠商轉入（視為 `0`） |
| `10` | 求職即時通 | 即時通求職者轉入（視為 `1`） |

* 廠商端（求才系統聊天室）顯示：`0,1,3,6,9,10`
* 求職端（求職主網聊天室）顯示：`0,1,4,5,9,10`
* 廠商寄出信件：`0`（廠商端）＋`5`（求職端）
* 求職者寄出信件：`1`（求職端）＋`6`（求才端）
* 求才回收訊息：`7`／求職者回收訊息：`8`

## 一般訊息

* MailType：一般訊息 `Type:0`
* 訊息內容：純文字訊息內容 `message string`

### 求才廠商

#### 廠商發出訊息

* `SendKind`：即時通送出 `9`（視為 0）／信件送出 `0`（廠商）；收回後 `7`（求才回收）
* 右下方顯示資訊
  * 發送帳號`oUser`
  * 帳號姓名 `oUsername`
  * 已讀／未讀狀態：顯示求職者 `已讀` / `未讀` `Readflag`
  * 發送時間（如 `已讀・13:20`）`dateSend`
* 收回操作（一般訊息）：判斷條件：發送時間 24 小時以內、且對方（求職者）尚未已讀 `RevokeFlag`（之後調整為 `sendKind`）時，hover 顯示 `收回` 操作；點擊後將訊息收回，前端樣式替換為已收回泡泡

### 面試邀約

| 訊息主旨 |判斷條件| 訊息區塊 | 面試資訊 |
| :--- | :--- |:--- | :--- |
| `面試邀約` |<ul><li>  `Type(MailType):1`&`InterViewKind:1`</li><li>舊資料：`Type(MailType):1`&`InterViewKind:2`</ul>| 廠商輸入的訊息`Message` |`Message`string內拆解：<ul><li>面試地點 `interViewAddress`</li><li>面試時間（1-3筆）</li><li>回覆期限 `wishReplyDay`</li><li>聯絡人 `contactPerson`</li><li>電話 `interViewPhone`</li></ul>|

註：`InterViewKind:2`是遠距面試已停用

* `SendKind:0`（廠商寄出信件；對應求職端 `SendKind:5`）

* 求職者尚未選擇／已選擇面試時間時，按鈕為可點擊狀態
  * 點擊`改時間`後，
    * 以iframe方式開啟現版 [信件通知Lightbox](https://hackmd.io/@1111-jobdocs/r1qJb-uXbx)
    * （現版要改）顯示信件通知指定`面試異動`
    * iframe尺寸：800x800
    * 帶入`rNo`、`eNo`、`MailType`（對應廠商點擊對應的類別）、`role`、`ResumeGUID`、`求職者姓名`
    * 點擊「寄出」後，即時將邀約內容按顯示為[面試異動](#面試異動)
  * 點擊`取消面試`
    * 顯示取消面試Modal`待補`
* 求職者已婉拒面試，按鈕為disabled
* 面試時間（最多三筆）全部過期時，按鈕為disabled

#### 求職者收到：面試邀約

* `SendKind:5`（求才發給求職系統信；對應廠商端 `SendKind:0`）
* 於求職系統顯示為靠左卡片，列出面試資訊（地點／時間（可多筆）／回覆期限／聯絡人／電話），卡內提供面試時間選擇＋ `同意` / `婉拒` 按鈕
* **點擊按鈕後的狀態**：
  * 點擊 `同意`（選定面試時間）：按鈕轉 disabled、寫入雙方面試行事曆、廠商聊天室頂部出現[面試行程確認區塊](/cj-xlto2SdOtVskt3TkhdA#136-面試行程確認區塊)、插入[意願狀態標籤](#意願狀態標籤)（綠色）
  * 點擊 `婉拒`：按鈕轉 disabled、插入意願狀態標籤（灰色）
  * 廠商發出的面試時間（最多三筆）全部過期且未回覆：卡片轉 disabled `已過期`
  * 後端寫入與通知詳見 [跨系統流程與後端邏輯](/uS9yE837SYedY9hQFneb6Q)

## 意願狀態標籤
