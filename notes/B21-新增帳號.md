## B.2.1 新增帳號

![image](https://hackmd.io/_uploads/B1BHI9fQ-x.png)

### 3 選填欄位

#### 3.1 手機號碼

* input 內可輸入數字，僅能輸入 10 位手機號碼
* 可與其他帳號重複
* 輸入內容後即時檢查格式，如格式錯誤則於下方顯示 error：請輸入正確的手機號碼（不含標點符號）

#### 3.2 備註

input 內可輸入中英數標點符號 30 字

#### 3.3 聯絡電話

* input 內僅可輸入數字
  * 區碼：最少 2 個數字，最多 5 個數字
  * 號碼：最少 6 個數字，最多 14 個字
  * 分機：可填寫 8 個字
* 輸入內容後，即時檢查格式，如格式錯誤則於右下方顯示 error：
  * 包含標點符號時：請輸入正確的電話號碼（不含標點符號）
  * 如輸入位數不足時（根據欄位顯示數字）：請輸入最少 N 碼

#### 3.4 傳真電話

* input 內僅可輸入數字
  * 區碼：最少 2 個數字，最多 5 個數字
  * 號碼：最少 6 個數字，最多 15 個字
* 輸入內容後，即時檢查格式，如格式錯誤則於右下方顯示 error：
  * 包含標點符號時：請輸入正確的電話號碼（不含標點符號）
  * 如輸入位數不足時（根據欄位顯示數字）：請輸入最少 N 碼

#### 4.3 確定新增

![image](https://hackmd.io/_uploads/H1g-5WT4bl.png)

* 進入 1.3 畫面時，4.3 按鈕為 disabled 狀態
* 當勾選任何一個權限checkbox後，4.3 確認新增按鈕改為 default 狀態
* 點擊後
  * 送出input資料新增 oUser
  * 發送通知信件給主帳號、目標帳號、所屬客服帳號
  * 寫入帳號新增 log 紀錄：如果主帳號無 email 位置仍須成功寫入紀錄，略過發送信件的syntax錯誤
  * 返回 B.2 帳號設定（位於列表第一頁），並顯示 toast 提示：帳號新增成功，請通知同仁確認信箱

* `取消`鈕：點擊後，關閉 modal 回到 B.2

### 2 快速新增

<img style="max-width:480px" src="https://raw.githubusercontent.com/sulfurcreek/main/614f2abac61278543021656e562922ca7f71e4db/.claude/assets/B2/B2_1_4_quick_add_modal.png">

#### 2.1 email

* 為 text field，必填，規則與 [B.2.1 新增帳號](#b21-新增帳號) E-mail 欄位相同
* 填寫 e-mail 後，即時檢查輸入格式與是否重複
  * 如格式不正確時，顯示錯誤樣態與錯誤訊息
  * 如 e-mail 重複時，顯示重複提示，**無 error 樣態**

<img style="max-width:500px" src="https://raw.githubusercontent.com/sulfurcreek/main/614f2abac61278543021656e562922ca7f71e4db/.claude/assets/B2/B2_1_4_email_duplicate_error.png">

<img style="max-width:400px" src="https://raw.githubusercontent.com/sulfurcreek/main/614f2abac61278543021656e562922ca7f71e4db/.claude/assets/B2/B2_1_4_email_shared_notice.png">

#### 2.2 帳號

* 為 text field，必填，規則與 [B.2.1 新增帳號](#b21-新增帳號)的 2.2 帳號規則相同
* 需判斷 2.1 email 是否已輸入內容
  * 尚未輸入時，text field 為 `disabled` 狀態
  * 輸入後：
    * 帶入 email `@` 前內容，切換為 default 狀態，可修改帶入內容
    * 當格式不正確時，顯示 error：僅允許英數、底線與 `.` 符號，不允許其他特殊符號
    * 即時檢查帳號是否與其他使用者重複
      * 如重複，則於右下方顯示 error，並提供三組隨機帳號
        * 由後端提供與現有 DB 內不重複之帳號，點擊後帶入帳號欄位中
        * 建議帳號最多 20 字，當 input 的值超過 18 字時，刪除最末的文字，將建議帳號補至 20 字
        * 訊息文案：您設定之帳號與其他用戶重覆，請改用其他帳號：`$帳號$後綴隨機三碼數字`、`$帳號$後綴隨機三碼數字&`、`$帳號$後綴隨機三碼數字`

<img style="max-width:500px" src="https://raw.githubusercontent.com/sulfurcreek/main/614f2abac61278543021656e562922ca7f71e4db/.claude/assets/B2/B2_1_4_account_duplicate_suggest.png">

#### 2.3 權限設定

* 為 chip 樣式，必填，僅可單選，進入畫面時預設不選擇
* 每個 chip 身份 hover 時顯示 tooltip，與 B.2.1 新增副帳號相同樣式與提示

<img style="max-width:300px" src="https://raw.githubusercontent.com/sulfurcreek/main/614f2abac61278543021656e562922ca7f71e4db/.claude/assets/B2/B2_1_4_tooltip_all_features.png">

#### 2.4 群組設定

* input 為 select 樣式，非必填，預設為空值
* hover heading 旁的問號 icon 時顯示 tooltip
* 需判斷登入帳號是否有群組管理權限，如果沒有權限時，顯示為 `disabled` 狀態，於下方顯示提示文字
* 點擊後顯示[選擇群組 modal](#選擇群組-modal)
  * modal 內可多選，最多 `100` 筆
  * 於 modal 內選擇完畢後，將群組名稱帶入 input 內，帳號權限代碼改為 `26`（不判斷上方的身份代碼）

<img style="max-width:300px" src="https://raw.githubusercontent.com/sulfurcreek/main/614f2abac61278543021656e562922ca7f71e4db/.claude/assets/B2/B2_1_4_tooltip_group.png">

<img style="max-width:500px" src="https://raw.githubusercontent.com/sulfurcreek/main/614f2abac61278543021656e562922ca7f71e4db/.claude/assets/B2/B2_1_4_group_no_permission.png">

##### 選擇群組 modal

<img style="max-width:700px" src="https://raw.githubusercontent.com/sulfurcreek/main/614f2abac61278543021656e562922ca7f71e4db/.claude/assets/B2/B2_1_4_group_select_modal.png">

#### 4.2 Buttons

* `新增`鈕
  * 預設為 `disabled` 狀態
  * 當 modal 內無錯誤且必填資料皆填寫時，新增按鈕切換為 default
  * 點擊後，送出 oUser 帳號資料進行新增，提供給後端以下資料：

    | 提供欄位 | 內容 |
    | :--- | :--- |
    | 帳號姓名 | email 位置 `@` 符號前文字 |
    | 帳號 | email 位置 `@` 符號前文字，如預期其他 oUser 重複則於後方新增四位隨機數字 |
    | 密碼 | 隨機密碼，與 B.2.1 隨機密碼規則相同 |
    | 權限 | 根據 [2.3 權限設定](#23-權限設定)選擇的身份，帶權限代碼 |
    | 群組 | 根據 [2.4 群組設定](#24-群組設定)選擇的群組，帶群組 No |

  * 透過快速新增的帳號需要有戳記，在首次登入首頁時，引導前往設定帳號資料（文件連結`待補`）
  * 確定新增完畢後，顯示 toast
* `取消`鈕：點擊後，關閉 modal 回到 B.2，不紀錄資料
