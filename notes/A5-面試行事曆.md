# A.5 面試行事曆

* User Story: `身為求才廠商，我想要在首頁快速查看近期已成立的面試行程，以便掌握當週面試安排並即時匯出或前往管理`
* Use Case:
  * `廠商登入後台首頁，系統依廠商狀態與職缺權限判斷是否顯示面試行事曆，並呈現當週已成立的面試行程列表`
  * `廠商點擊單筆面試行程，開啟面試行程面板查看詳情，並可前往信件對話編輯或取消該筆面試`

## 初始化

### 進入路徑

本組件為首頁內嵌區塊，無獨立進入路徑；廠商登入後台首頁即顯示（或不顯示，見下方權限判斷）。

### 權限判斷

進入首頁時，依序驗證以下條件（代碼定義見 [[REF] 求才系統代碼表](/B1j3sN-bzx)）：

| 權限條件 | 代碼 | 不符合時的處理 |
| :--- | :---: | :--- |
| 廠商需為指定狀態 | `oStatus = 1` 或 `oStatus = 6` | 其他狀態時，整區顯示為 `1 無行程樣式`（視覺上等同無資料狀態，非跳轉或 Alert） |
| 職缺管理權限（篩選範圍用，非顯示／隱藏開關） | `代碼26`／`代碼27` | 無此權限時，顯示廠商**全部職缺**的面試行程；持有權限則僅顯示**可管理職缺範圍**內的行程 |
| 編輯／刪除面試行程權限 | `代碼15` | 無權限時，`面試行程面板` 隱藏「編輯」（`1.4.2.1`）與「刪除」（`1.4.2.2`）按鈕 |

### 資料載入

* 通過上方權限判斷後，呼叫 `Api/v1/calendar`，帶入參數 `99`，取得廠商所有狀態的面試資料：`0` 邀約中／`1` 已成立／`2` 已過期
* 頁面僅顯示狀態為**已成立**（`1`）的面試行程；其餘狀態資料用途 `待補`

| 狀態 | 觸發條件 | 畫面呈現 |
| :--- | :--- | :--- |
| 載入中 | 呼叫 `Api/v1/calendar` 尚未回傳 | `待補` |
| 有資料 | 已成立面試資料筆數 > 0（且權限判斷通過） | 顯示 `1 面試行事曆`（有行程畫面）：週曆列＋當日行程列表 |
| 無資料 | 已成立面試資料筆數 = 0，或廠商／職缺狀態不符合權限判斷 | 顯示 `1 無行程畫面` |
| 錯誤 | API 呼叫失敗 | `待補` |

## 1 面試行事曆

* 判斷結果為「有面試行程」時：
  * `1.3` 固定顯示週日至週六的週曆列
  * 依所選日期顯示當週的面試行程
  * 有面試行程的日期，於該日期右上角以 badge 顯示面試數量
  * 點擊 `1.3` 任一日期，切換下方 `1.4` 列表，查看該日期的面試行程
  * 點擊「看全部」（`1.2`），前往面試行事曆頁 `oInterView.aspx`
* 判斷結果為「無面試行程」時，顯示 `1 無行程畫面`

## 1.1 匯出行事曆

按鈕顯示規則：

* 顯示為 `1 無行程畫面`（沒有行程）時，不顯示此按鈕
* 廠商 `oStatus` 非 `1` 或 `6` 時，不顯示此按鈕

匯出規格：

* API 名稱：`api/calenderexport`
* 檔案格式：`.ics`
* 匯出範圍：由今日開始，往後全部已確認（已成立）之面試邀約

## 1.4 當日行程列表

* 顯示指定日期**已成立**的面試行程（其他狀態不顯示），由面試時間最早至最晚排序
* 預設選擇當天日期
* `1.4.1` 於列表上方顯示當日面試數量
* 超過 5 筆時，列表顯示 scroll，可查看當天所有面試行程

### 1.4.2 今日面試行程單筆項目／面試行程面板

每筆面試行程顯示欄位：

| 欄位 | 說明 |
| :--- | :--- |
| 時間 | 面試時間 |
| 職缺名稱 | 面試對應的職缺名稱 |
| 求職者照片 | <ul><li>求職者未上傳照片時，顯示 default 圖片</li></ul> |
| 求職者姓名 | 求職者姓名 |

點擊單筆面試行程，開啟**面試行程面板**（`1.4.2`），顯示已建立的面試行程邀約詳情：

* 求職者照片與姓名：點擊後前往現版履歷詳細頁（`https://recruit.1111.com.tw/lightBox/ResumeDetail.aspx?` 帶對應信件與履歷參數）
* 面試資訊欄位：
  * 求職者代碼
  * 面試職缺名稱
  * 面試時間
  * 面試方式
  * 面試地址
  * 面試官（帳號姓名）
* 點擊右上角關閉行程面板

#### 1.4.2.1 編輯面試行程

* 點擊後，前往現版信件對話（`https://recruit.1111.com.tw/ResumePoolNoticeMailDetail.aspx?` 帶對應信件與履歷參數），並帶入信件類別／面試異動
* 需判斷是否具備編輯面試行程權限（`代碼15`），無權限時隱藏此按鈕（見 `初始化 > 權限判斷`）

#### 1.4.2.2 刪除面試行程

* 點擊後，前往現版信件對話（`https://recruit.1111.com.tw/ResumePoolNoticeMailDetail.aspx?` 帶對應信件與履歷參數），帶入信件類別／面試異動／取消面試
* 需判斷是否具備編輯面試行程權限（`代碼15`），無權限時隱藏此按鈕（見 `初始化 > 權限判斷`）
