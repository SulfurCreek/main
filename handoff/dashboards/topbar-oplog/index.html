    計算口徑

    資料串連
    同一次登入的 sessionId 在登入成功、Topbar 抵達事件相同；一個 Session ＝ 1 筆 login:success ＋ N 筆 topbar:view，依時間戳記排序成動線。
    活躍廠商
    期間內有任一 Session 的 OrganNo 去重；區間模式是整段去重，不是每日加總。
    VIP 狀態
    取 metadata.oStatus（0 普通會員／1 VIP／2 過期／3 關權／4 免費VIP／5 免費曝光／6 準VIP）；同一廠商期間內若變動，以該 Session 當下值計算。
    網段
    由事件 IP 判斷內網／外網，兩者都納入統計：KPI、每日趨勢、內外網表、頁面使用表皆並列外網與內網；篩選「網段」可單看其一。
    頁面
    Topbar 事件的 URL 路徑對應〈附錄：頁面一覽表〉（Sitemap）。履歷詳細頁、履歷列印頁不渲染預設 Topbar，不會出現在本後台。
    篩選套用方式
    日期、VIP 狀態、網段、廠商、Session ID 以 Session 為單位過濾；功能分區／抵達頁面保留「期間內抵達過該處的 Session」，其完整動線仍會顯示。
    期間內無紀錄
    頁面一覽表中有、但期間內沒有任何 Topbar 抵達的頁面，可對照文件的「op log 抵達確認」欄。
    待確認
    • Topbar 事件是否帶有 OrganNo／廠商名稱，或需用 Session ID 回查登入事件取得。
    • 舊版 wireframe 的「產業 tCodeTrade」「裝置」篩選只存在於登入事件；若要加回，需確認 Topbar 事件可透過 Session ID 帶入。
    • 後台載體（Grafana、客服後台或獨立報表）與查詢 API 驗證方式。
