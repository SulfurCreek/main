2.2履歷狀態 Tag（單選）

六選一：不拘（預設）／未讀／已讀／追蹤中／有備註／已通知。單選，點選後即時更新下方列表（從碩網搜尋結果內篩選）。選「未讀」→ 3.1 變成 3.1a。

3.1a兩個數字

「共 N 筆履歷，已排除 M 筆已讀　查看＞」
  • N = 搜尋結果名單總數，換頁不變。
  • M = 該分頁隱藏的已讀筆數（搜尋機制只能每頁個別判斷），換頁會變。
  • M = 0 照常顯示「已排除 0 筆已讀」，連結行為不變（S4）。
  • 3.2 右側元件往右顯示（S2 以 ▲ 標出 S1 時 3.2 的位置）。

3.1a「查看＞」動作

取消「未讀」，2.2 回到「不拘」，3.1a 還原成 3.1（S6）。
