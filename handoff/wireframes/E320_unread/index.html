2.2履歷狀態 Tag（單選）

六選一：不拘（預設）／未讀／已讀／追蹤中／有備註／已通知。單選，選一個會取消另一個。選「未讀」→ 3.1 變成 3.1a。

3.1a兩個數字

「共 N 筆履歷，已排除 M 筆已讀　查看＞」
  • N = 搜尋結果名單總數，換頁不變。
  • M = 當前這一頁被隱藏的已讀筆數，換頁會變。
  • M = 0 照常顯示：「已排除 0 筆已讀」，「查看＞」照舊（S4）。
  • 3.1a 比 3.1 長，3.2 全選與 3.3~3.7 整體往右移（S2 以虛線標出 S1 位置）。

3.1a「查看＞」動作

取消「未讀」，2.2 回到「不拘」，3.1a 還原成 3.1（S6）。

空 avs空 b差異（S7）

  • 觸發：a = 搜尋名單沒有符合條件的求職者；b = 名單有資料，但本頁履歷全被「未讀」隱藏（含最末頁整頁皆已讀）。
  • 按鈕：a 有「重新設定條件」Primary（2.1c 相似履歷搜尋不顯示）；b 沒有任何按鈕，不設獨立「下一頁」。
  • 5 分頁套件：a 不顯示；b 照常顯示，翻頁靠它。
  • 3.1a：b 仍顯示。
  • 4 求職者卡片：兩者皆不顯示。
  • 版面：b 比照 a（標題＋敘述置中）。

3.2全選

只全選當前分頁的履歷。S3 的全選與單筆都已勾。

3.3~3.7多筆操作

發信通知／加入追蹤／列印／下載／轉寄。
  • 初始 disabled（灰字）；勾選任一筆後 enabled（藍色連結）。
  • 廠商 showfield&33554432 或帳號權限 51 沒有時，整列隱藏。
  • 編號一律 3.3~3.7，文件已移除 3.8。
