# F12. C 端行動產品與 0→1 初創 / Consumer Mobile & 0→1 Product Creation

> **履歷叢集 / Résumé cluster**：Product Strategy & Vision ＋ Execution & Delivery
> **證據期間**：2016/06–2022/03（尚凡國際、思維特）——見[完整職涯時間軸](prior-roles.md)

**定義 / Definition**：為**消費者端（B2C）行動產品**做完整的產品定義與營運，涵蓋 **iOS／Android／RWD** 三端；
既能把產品**從零帶到上線（0→1）**，也能持續營運既有產品。
*Own consumer-facing mobile products end-to-end across iOS, Android and responsive web — both creating products
from scratch (0→1) and operating mature ones.*

- **實際展現 / In practice**：
  - **0→1 初創**：共 **3 個從零初創的服務**＋**4 個既有產品**的營運——包含 **JustDating App 與其 Web 版**、
    **KOOL 網紅人力銀行 App**、**SweetRing 交友 App**。
  - **完整定義鏈路**：從提案 → user story → wireframe → prototype，用以向利害關係人展示**架構與 user flow**。
  - **時程壓力下交付**：在嚴格時程內多次交付產品初版上線，達成**穩定且可用的 MVP**。
  - **多端體驗優化**：同時優化 **iOS、Android 與 RWD 網站**的 UI／UX。
  - **營運數據監測**：以 iOS／Android 官方後台、第三方數據平台（**App Annie**）與用戶資料做分析，
    據以產出改版或促銷決策。
  - **流失防治**：研究**中國行動應用市場案例**後，設計**召回策略（call-back）降低用戶流失**〔待補數據：流失下降 %〕。
  - **配對機制設計**：改良使用者之間的 **Q&A 互動機制**，以刺激更多配對與有意義的對話。
- **公開佐證 / Public corroboration**（見[證據頁](evidence-prior-products.md)）：SweetRing 由 **Sweet Tech Ltd.** 發行、iOS **2016-07-12 上架**（本人 2016/06 到職，即上架當月在隊）、Google Play **500 萬次以上下載**、至今仍營運；JustDating iOS **2020-03-24 上架**（任期內）、**100 萬次以上下載**。**JustDating 與 Juicy 皆曾登上商店 trending 榜與暢銷榜**〔待補：商店／市場／分類／名次〕。KOOL 與 Juicy 已下架。
- **工作證據 / Evidence**：本人前一版履歷所載之 Sunfun（2018/01–2022/03）與 Sweet Tech（2016/06–2018/01）職責與成果。
  部分產品已下架，不影響角色與成果的成立（見[前段職涯](prior-roles.md)的處理方式）。
- **資深度訊號 / Seniority signal**：**0→1 的完整 ownership** 是現職（1111 平台 1→N 治理）缺少的互補面向；
  兩者合起來代表「**能從無到有立產品，也能治理既有大型平台**」——資深 PM 最被期待的完整光譜。
  另有一條貫穿全職涯的主軸：**配對型雙邊市場**（交友配對 → 網紅媒合 → 人才媒合），領域知識可直接遷移。
