# 審查者的質疑｜JD03 Pi錢包 產品經理

- **誰在想**：HR
- **讀到哪一句**：Peach 網頁付款占營收由 24% 升至 80% 以上
- **心裡怎麼想**：這是我們最想看到的金流經驗，但 80% 是他推出來的，還是 Apple 抽成政策逼大家轉、行銷一起推的？
- **這個疑問會讓我**：面試追問
- **要打消疑問需要看到**：他負責的串接規格範圍、轉換流程設計，以及同期其他影響占比的因素

- **誰在想**：用人主管
- **讀到哪一句**：與外部合作夥伴議定查詢 API 時，先處理可能被濫用的風險
- **心裡怎麼想**：簽章、防重放、頻率限制講得出來，懂 API 這點讓我想約；但查詢 API 跟交易 API 差很多，對帳、冪等、退款他碰過嗎？
- **這個疑問會讓我**：仍然約談
- **要打消疑問需要看到**：一次處理交易失敗、重送或對帳差異的實際案例

- **誰在想**：用人主管
- **讀到哪一句**：現任 1111 招募系統 Product Owner
- **心裡怎麼想**：最近四年都在 B2B 招募，支付是 2021 以前的事，而且是 App 訂閱付款，不是高頻交易，也沒看到銀行或政府對接。
- **這個疑問會讓我**：面試追問
- **要打消疑問需要看到**：近期仍有接觸金流或銀行端的證據，或說明為何轉向支付與如何補上領域知識

- **誰在想**：HR
- **讀到哪一句**：男性 DAU 在 6 週內由約 3,200 增至 1.25 萬
- **心裡怎麼想**：寫明是「上線與行銷導流期間」，算誠實，但多半是既有用戶搬家，算不上產品成長。
- **這個疑問會讓我**：降低信任
- **要打消疑問需要看到**：新用戶與導入用戶的拆分，以及導流後的留存數字

30 秒第一印象：規格與系統規則拆解很紮實、碰過金流串接的資深 B2B PM，但支付經驗偏舊、需要確認能否接上高頻交易場景。
