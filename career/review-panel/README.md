# 履歷審查模擬小組 / Resume Review Panel

> 2026-10-06 建立。**全部人物皆為虛構**，用來當作「同儕基準」與「審查視角」，不是真實求職者或真實招募者。
> 公司一律以產業描述代替真實公司名稱，避免冒用。

| 路徑 | 內容 |
| :--- | :--- |
| `research.md` | 上網查到的審履歷研究與來源（persona 設計依據） |
| `candidates/index.md` | 50 位資深 PM 求職者 persona 總表（背景、產業、品質分級） |
| `candidates/resumes-*.md` | 50 份中文履歷（每檔 10 份） |
| `reviewers/hr.md` | 10 位人資 persona 與審查角度 |
| `reviewers/hiring-managers.md` | 10 位用人主管 persona 與審查角度 |
| `../skills/resume-review-panel/SKILL.md` | 把上述審查流程做成 skill |

品質分級（A／B／C）是**撰寫時刻意設計**的：A＝成果具體、軟實力有行為證據、語氣自然；B＝內容可以但有明顯缺點；C＝常見問題（職責清單、術語堆疊、無數字、AI 腔）。用途是校準審查者：好的審查流程應該能把 A 排在 C 前面。
