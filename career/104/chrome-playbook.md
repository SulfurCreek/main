# Claude in Chrome 操作手冊：建立 104 履歷

> 使用者在 Chrome 開兩個分頁：① 104 履歷編輯頁（已登入）② 本 repo 的 `career/104/resume-104.md`（GitHub 網頁，分支 `claude/happy-lamport-ljis8c`）。
> 每次把下面一段指令貼給 Claude in Chrome。一次只做一個區塊。

## 共通規則（每段指令開頭都要貼）

```text
你要協助我在 104 人力銀行建立履歷。規則：
1. 內容只能取自我另一個分頁的 resume-104.md，逐字照抄，不要改寫、不要補字、不要自己編數字。
2. 標成〔待填〕或〔待補〕的欄位一律不要填，跳過並在最後列給我。
3. 每個區塊填完後，「儲存」按鈕按下之前先停下來，截圖或列出你填了什麼，等我說「OK 儲存」才按。
4. 絕對不要按「投遞」「應徵」「公開履歷」「刪除」，也不要修改帳號設定、密碼或個人資料區。
5. 下拉選單或標籤只能從 104 提供的選項中選；找不到完全一樣的選項，列出最接近的 2–3 個讓我選，不要自己決定。
6. 若欄位字數超過 104 上限，停下來告訴我超過多少字，不要自己刪減。
7. 若頁面跟描述不符（找不到欄位、跳出驗證），停下來描述畫面給我看。
```

## 步驟

### 步驟 1：建立新履歷並命名

```text
（貼上共通規則）
在 104 建立一份新履歷，履歷名稱用 resume-104.md 第 0 節的「履歷名稱」。
先不要動公開狀態與封鎖公司，那兩項我自己設定。
```

### 步驟 2：求職條件

```text
（貼上共通規則）
左側選單點「求職條件」→「新增」。照 resume-104.md 第 2 節填：希望性質、上班時段、可上班日、希望地點、遠端工作、希望職稱、希望職類。
希望待遇那一項不要自己選，停下來把四個選項（面議／依公司規定／論件計酬／自訂薪資）給我看，我來選。
「希望工作內容」「希望從事產業」兩張擴充卡片先不要點開。
```

### 步驟 3：學歷

```text
（貼上共通規則）
填 resume-104.md 第 3 節「學歷」兩筆。淡江大學的畢業年份是〔待補〕，填到那裡就停下來問我。
```

### 步驟 4：工作經歷（一次一家公司）

```text
（貼上共通規則）
點「新增」；若先跳出「編輯總年資」，停下來給我看選項，我選好才繼續。接著新增一筆工作經歷，內容用 resume-104.md 第 4.1 節（1111 人力銀行）。
公司名稱、職稱、起訖時間、產業、職務類別、管理責任照表格填；
「工作內容」把 text 區塊的內容整段貼進去，保留每行開頭的「・」與換行。
填完先停下來讓我檢查。
```

完成後依序把「4.1」改成 4.2、4.3、4.4 重複執行。

### 步驟 5：語文能力與證照

```text
（貼上共通規則）
語文能力：技能專長 › 語文能力，語文類型選外文，外文種類英文，聽說讀寫照 resume-104.md 第 5 節。
證照：技能專長 › 資格認證，會開「資格認證中心」彈窗。用搜尋框找 resume-104.md 第 7 節四張證照，
找到就勾「加入本份履歷」；搜不到的，點右上「新增」手動新增。每張找不到或有疑問都停下來問我。
```

### 步驟 6：專長

```text
（貼上共通規則）
技能專長 › 專長，每次「+」新增一筆，只有「專長名稱」一個欄位。依 resume-104.md 第 6 節的清單，
一筆一筆新增，每筆儲存前停下來等我說 OK。可以每 3–4 筆一起給我確認一次。
```

### 步驟 7：自傳

```text
（貼上共通規則）
自傳／推薦人 › 自傳，中文自傳上限 4000 字、英文 8000 字。把 resume-104.md 第 8 節的中文自傳整段貼進「中文自傳」欄位，保留段落之間的空行。
其中〔待補〕那一行先不要貼，貼完告訴我目前字數。
若 104 有英文自傳欄位，再把第 9 節貼進去。
```

### 步驟 7b：專案成就與附件

```text
（貼上共通規則）
附件／專案 › 專案成就，依 resume-104.md 第 11 節新增三筆。素材欄不上傳，專案連結留空。
第 1 筆（跨系統聯絡人才）標了「使用者核可後才填」，我沒說核可前跳過。
「附件」那一節不要新增（作品集網址還沒有）。
```

### 步驟 8：最後檢查

```text
請逐一打開這份 104 履歷的每個區塊，跟 resume-104.md 比對，列出：
(a) 內容不一致的地方；(b) 還空著的欄位；(c) 104 提示「建議補充」的項目。
只列出來，不要修改。
```
