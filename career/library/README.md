# 原始事實彈藥庫（Raw Fact Vault）使用規則

1. **定位**：本目錄（`facts-1111.md`、`facts-prior.md`、`profile.md` 等）是本人存放真實經歷、專案筆記與統計數據的「原始素材倉庫」。
2. **與履歷寫作的關係**：
   - 寫履歷時，從此處提取真實專案與數字作為彈藥，**但嚴禁照抄此處的筆記句型、內部術語或冗長的統計計算備註**！
   - 過去為了防禦性審查而在筆記中寫下的長串分母說明或時間口徑，在履歷正文中應大刀闊斧精煉為最直覺、最具商業價值的表達。
   - `decisions.md` 僅作歷史參考，不再作為限制寫作發揮的緊箍咒。
