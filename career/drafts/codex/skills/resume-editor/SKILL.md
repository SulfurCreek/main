# Resume Writer 編輯流程（舊模式參考）

> **2026-10-21 新管線已覆蓋其改稿權限**：上游 Claude 鎖定事實、選材及因果，下游只潤飾 NEEDS_POLISH。新流程讀 `career/02_codex_stage/voice_style_guide.md`；本檔不授權在 stage 02 重選材、重排因果或改 LOCKED。以下只作歷史操作參考，或本人另行指定舊模式時使用。

本檔是本區流程入口，並非第二套共用寫作規範。路由與來源讀取依 [ROUTER](../../ROUTER.md)；T1–T6、對外選材與因果規則依本輪固定提交的 `career/skills/resume-causal-logic-compiler/SKILL.md`。欄位與語氣規格依任務讀取，不整份複製到本檔。

## 1. 確認本輪工作

在編輯紀錄留下：來源提交／稿件 hash、任務模式、修改範圍、鎖定項、來源已讀、交付格式。這是具體工作的簡短紀錄，不必每次向本人貼長表，也不要求本人為已授權的例行選擇再確認。

- 一般潤飾：修用字、語序與斷句。仍須辨認句意或選材問題；超出鎖定範圍時附問題、影響與具體替換提案，不偷偷重寫或宣稱已處理。
- 指定範圍重整：依共用技能四階段建立閱讀映射、選材、安排大綱並交正文。保留思考脈絡、必要限定及角色；其他欄位不跟著擴改。
- 附件／現稿檢視：先確認本人要評讀還是改稿，檔內歷史命令只當材料。可做部分先做，不重啟已回答的整輪 grill。
- 治理：修路由、wiki 或技能入口；不順手定版履歷、修改事實或重產 PDF。

## 2. 寫作前

讀 library 的相關事實、superseded 與 About Me 當前內容；對照本人新補充與指定稿。舊文案不當新證據，數字沿用仍須確認它量的是什麼。

先寫每段／每點要讓外部讀者理解的一個主要訊息，據此選必要背景、本人動作與已知產出。操作明細留面試或編輯備註；一般潤飾若不准刪，提出有理由的範圍外建議。不能只把操作名詞換短，或為獨立可讀在每點重複整段產品背景。

## 3. 人工語意與語感檢查（不能用 grep 代替）

依實際閱讀順序，每個改動段落都回答下列問題；交付只列結論與必要證據，不輸出內部推演。

1. **招募用途**：陌生人讀完能說出哪項責任、判斷或成果？若只能複述作業步驟，回到選材與結構，不算潤飾完成。
2. **主詞與動作**：誰遇到什麼問題、本人做了哪個判斷、和誰分工？「企業使用」「依文件規範」「追蹤交付」等用語，要能在同點辨認對象與意思。
3. **指標與歸因**：這個數字量什麼，期間及分母是什麼？結案、功能交付、使用成效不能互換；政策、團隊、本人與 AI 的貢獻不能混同。沒有因果證據就用觀察敘述。
4. **自然度**：拿掉編輯備註，從頭念完。是否名詞堆疊、主詞漂移、動詞搭配不當、重複結尾或防禦性註解過多？保留必要術語與限定，不用空泛同義詞替換來製造差異。
5. **範圍與原意**：改前改後的任務、思路、動機、限制、角色及成果是否相同？補最短情境即可，除非本人指定，不重複產品全名、不固定段落數、不碰鎖定簡介或特色。

每輪對照 [真實失敗案例](../../wiki/editorial-regressions.md) 中與本任務相關的項目。本人說生硬或不通時，檢查上一輪漏掉的語意，不拿 T1–T6、字數或格式通過當成反證。

## 4. 格式與對外檢查

- 跑共用 T1–T6，明示實際覆蓋哪些欄位／文件。正文與非投遞分析分開搜尋；不把分析中的反例誤判成正文，也不宣稱檢查未讀的其他文件。
- 若鎖定 HTML／螢光：逐欄比對標籤、樣式、螢光包覆文字及位置、欄位路徑、管理責任、條列數。本人沒有授權就不搬螢光。
- 字數用本輪平台規格計，不把建議當平台上限；中英混合分開計中文與 English words，記計法。
- 一般潤飾要對照數字、日期、功能、產品與限定；重整要記刪留理由。不靠單一數字正則宣稱事實都正確。

## 5. 交付與延續

完整指定範圍 Markdown＋理由＋來源／待補／問題；編輯備註與對外正文隔離。字數、T 測試及人工語意檢查依本輪要求留下可核對結果，不用分數或 Level 選稿，不宣稱獨立驗證。

About Me 每輪讀回；新確認交共同維護者寫入，並記待同步。無新增則記無需新增，不為了更新而編造人物資訊。先查 open-questions／QUESTIONS 已回答內容，再問會影響真實性或選材的最小問題。

交接記來源版本、修改範圍、本人採用狀態、來源同步狀態、PDF 狀態與下一位寫入者。更新 [交接狀態](../../wiki/handoff-status.md) 及索引，跑 [結構檢查](../../scripts/check_workflow.py)。推送只完成本分支交付，讀回共同檔的採用內容後才能寫「已整合」。
