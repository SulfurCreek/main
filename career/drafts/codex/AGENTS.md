## Step 1：同步並鎖定來源

明確更新遠端追蹤參照：
```sh
git fetch origin refs/heads/claude/happy-lamport-ljis8c:refs/remotes/origin/claude/happy-lamport-ljis8c
```
本人指定完整SHA時用該基底；未指定才解析最新遠端SHA。完整讀指定草稿與既有候選稿，記錄草稿／規範／驗證器SHA；固定基底不必等於遠端最新提交。取得失敗不以舊稿冒充。無關歷史搜尋、反覆diff或狀態查詢不做。

## Step 2：按語言潤飾、全文自審與初驗

只用對應語言章節。所有授權可改區塊重新審讀，不因POLISHED跳過；本人限範圍時全文審讀、範圍內修改。保留數字、日期、限定、責任、狀態、鎖定與directive原文。
跨欄去重直接處理，不能用不得重選素材拒改。刪整個案例、改定位或未授權增刪段落交上游；本人本輪明確授權則依指示。
中文完整履歷按其實際七大模組檢查；英文及信件依實際欄位檢查，不硬套不存在的章節。文體檢查依語言，不共用動詞、日期、句首或自傳規則。
完成初稿後執行適用Gatekeeper，Exit 0才進盲審。未實作的語氣拆分腳本不當成已存在工具。

## Step 3：語言隔離盲審、處置閉合與重讀

### 3A. Sub-Agent Proof Gate

每輪成品交付須獨立只讀子代理，不能用自審、腳本通過或前輪結果代替。單純規則維護只審規則及提示路由，不虛構成品盲審。
使用不繼承歷史的代理，只提供去內部HTML註解的完整對外候選與獲准JD；不提供原始含註解路徑、內部規則、鎖定表、上游、事實庫或前輪意見。不新增暫存檔。
中文候選使用中文招聘閱讀提示及中文回覆，標準只來自中文章節。
英文候選使用全英文提示、母語英文招聘閱讀者角色與英文回覆，標準只來自英文章節；英文自然度審查不取代另有要求的JD盲審。
混合候選各段分流；可用不同代理分別回報相應語言，不把另一語言的風格標準帶入。
提示範本分別見對應章節；審讀職級／權責可信度、商業價值、陌生人理解與自然度，不新增事實或強迫編問題湊數。
重做盲審用新隔離代理；同一代理複查標為非盲複查。隔離失敗明示未完成。

### 3B. 三分類處置與防搖擺

| 分類 | 處置 |
| --- | --- |
| ✅ 已修正 | 在事實與授權範圍內，將真實語病、理解障礙及重複直接改入，附Before → After，不只出報告。 |
| 🔒 不採納 | 指出與來源事實、本人明文裁定或適用語言規則的具體衝突；不能用另一語言規則或泛稱本人指定駁回純措辭問題。 |
| ⛔ 上游阻擋 | 先修可改部分，再附可複製指令：來源SHA、位置、原句、替換句、需調整鎖定詞及不可變事實。工具語言路由不相容也交上游，不改腳本。 |

不因新審稿者偏好反轉已裁定語序；不以數字前置製造概念偷跑，不在功能定義前放驗收規則，不重複長限定，不刪強制口徑與責任，也不僅為主觀同義偏好反覆換詞。這些是理解與事實護欄，具體文體門檻仍只取對應語言章節。
對單一無新依據的A↔B爭議停止往返，但不放行其他未解錯誤。Claude為跨輪Final Arbiter，本人保留定版權；Codex不讀事實庫代替Claude裁決。

### 3C. 按語言重讀與交付證明

改稿後完整重讀該語言成品；中文只跑中文章節的語感檢查，英文只跑英文章節的體裁與自然度檢查。混合文件分段處理，事實不變。
備妥本輪子代理讀取範圍、原始挑刺摘要、逐項三分類表與實際修改。未完成盲審或可改問題未閉合，不宣稱成品完成。
規則維護以實際規則與提示檢查表回報，不捏造成品審讀或改稿。

## Step 4：最終Gatekeeper、提交與交付

固定SHA讀取對應驗證器，在repo根目錄以Bash、set -o pipefail執行，沿用實際參數：
```bash
git show <完整來源SHA>:career/scripts/verify_polish.py | python3 - --local-codex
git show <完整來源SHA>:career/scripts/verify_line_profile.py | python3 - <英文成品路徑>
git show <完整來源SHA>:career/scripts/verify_letter.py | python3 - <推薦信路徑> --job "<職缺名>"
```
以上是依任務擇用的模板，不原樣執行佔位文字；不同驗證器不能互代。支付參數或語言／文件類型參數依該SHA腳本實際介面。
整條命令須Exit 0且輸出預期成功訊息；有區塊計數時核對實際數量。另核對授權範圍、JSON、數字與限定。中文警示不拿來判英文品質，英文通過不代表中文通過。
失敗立即中止相依commit/push；可修範圍內修後重驗，不改腳本、不造假輸入。驗證通過才commit（career:）與push codex/resume-writer；本人要求暫不推送時除外。不force push，遠端新提交正常整合。
規則維護依本人指定跑既有中英文Gatekeeper作相容檢查，不修改未授權成品；若既有稿不過且超出授權範圍，回報阻擋，不推送。
交付附來源SHA、實際驗證命令／結果、成品或規則連結、commit，以及相應語言的挑刺與處置表。只有實際修改的欄位才回報變更；無PDF任務不追加PDF驗收。
