# PDF 版型（2026-10-13 使用者指定）

> 回 [`../SKILL.md`](../SKILL.md)。使用者提供 Enhancv 範例（Brad Jensen，雙欄），指示「之後的 PDF 都套這個格式」。

## 版型規格

| 區塊 | 規格 |
| :-- | :-- |
| 抬頭 | 姓名 24pt 粗黑；職稱行藍字（`｜` 分隔）；聯絡資訊一列（Email、電話、地點），前置藍色線條圖示 |
| 版面 | 雙欄：左 63%（專業摘要、工作經歷）、右 37%（關鍵成果、專業技能、學歷、求職條件） |
| 區塊標題 | 粗體、字距、下方 3px 黑線 |
| 經歷抬頭 | 職稱黑字粗體 → 公司藍字 → 日曆圖示＋起訖；範圍行灰字 |
| 右欄 | 關鍵成果：粗體標題＋一句內文，點線分隔（txt 有〈關鍵成果〉段、格式「- 標題：內文」才出現）；技能：類別粗體、內容在下 |
| 自傳 | 雙欄後整寬接續，不強制換頁 |

## 產出

```bash
python3 scripts/render_twocol.py <resume.txt> <out.html> --location 台北市
node scripts/mkpdf.js <out.html 絕對路徑> <resume-vX-twocol.pdf>
```

## 與 ATS 規則的衝突與處理

- 雙欄 PDF 用位置抽字的解析器會左右交錯（v8.1 實測 `parse_check.py` 還原率 77%，單欄 99%+）；標題、日期、Email 仍全數可讀。
- **處理**：雙欄版＝給人看（Email 直寄、面試印出、作品集附件）；**投遞 ATS 系統或求職網站上傳時用單欄版**（`render_html` 舊版型）。兩份一起產，檔名 `-twocol.pdf` 區分。
- 104 履歷是表單欄位，不受影響。
