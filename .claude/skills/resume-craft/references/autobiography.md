## A. 自傳 essay（3b）

先決定這份自傳要讓讀者相信的 3–4 件事，每件事寫一篇 essay，**先寫完整、不管字數**：

| 段落 | essay 要回答 | 素材 |
| :--- | :--- | :--- |
| 1. B2B 產品判斷 | 遇到什麼分歧或限制、我怎麼查證、怎麼決定、結果 | 步驟 3 essay 中「有取捨」的那篇（例：承攬制、配對規則、Roadmap 取捨） |
| 2. 商業化成果 | 假設是什麼、怎麼驗證、數字、後續決定 | B2C 定價實驗、付款導流 |
| 3. 跨部門或跨國推動 | 沒有職權時怎麼讓人動起來 | 在地化、金流串接、客服封測 |
| 4. 出狀況時（選） | 事件 → 我的處置 → **結果**；沒有結果就不寫 | library 的事故紀錄 |
| 5. 離職動機 | 見下方〈離職動機〉 | `library/profile.md` §7 |
| 6. 前 90 天（選） | **只在有目標 JD 時寫**，從 JD 推出 | 目標 JD |

每篇 essay 開頭標兩行：

```text
想讓讀者相信：（一句話，例：我會先查清楚再改規則）
素材來源：（library 條目或步驟 3 essay 編號）
```

essay 本文依「痛點或處境 → 我的解法（哪裡跟一般做法不同）→ 這件事讓我相信什麼（體悟）」寫（2026-10-12，`career/style/de-ai-reverse-engineering-source.md`）；體悟要是主觀業務洞察，不是口號；**限定在「我」與該情境**（例：「這件事讓我習慣先把定義對齊」），不寫成「多半／大多數／往往」的通則（2026-10-12 盲審 v8：3／5 輪判為概括性絕對語氣）。

規則：

- 自傳**不重述履歷條列的數字**（2026-10-12 盲審：重述數字被判「自我推銷、人味低」）；要用就換角度寫「為什麼這樣決定」。
- 事實只取 library 與步驟 3 essay，**使用者的口述當事實、不當句子**：照 skill 重寫，不加沒說過的細節。
- 不寫家庭背景、興趣；不寫「熱愛學習／希望來學習／即戰力／高適應力」這類形容。

## 離職動機（為什麼想離開）

### HR 為什麼問

1. 探詢動機。
2. 找出你的「地雷區」評估留任：你無法接受的事（文化、主管風格、工作性質），新公司會不會也有。
3. 用過去預測未來：一直把問題歸給外部環境的人，進來後也會有同樣摩擦。

### 不能寫的三種理由（即使是真的）

| NG | HR 的聯想 |
| :--- | :--- |
| 跟主管管理風格不合 | 會不會是你的個性或配合度有問題 |
| 跟同事相處不好 | 溝通或團隊協作有問題 |
| 工時太長、常加班 | 配合度低；遇到配合度高的候選人就被比下去 |

另外不寫：批評前公司或組織（「停擺」「前任主管沒做完」「能做的我已經做到」）、薪資。

### 寫法：把推力轉成拉力

順序固定三步（原文公式）：

1. **先寫貢獻**：在現職主導了什麼、學到什麼（具體、有數字，跟前面段落不重複）。
2. **再寫「已到一個階段」**：用中性說法，例如「工作已趨於平穩」「組織發展到了一個階段」「在現有架構下較難有突破」。不指向任何人。
3. **最後寫想投入的方向（拉力）**：想累積什麼樣的經驗、想挑戰什麼；有目標 JD 時，接上「貴公司的〔某項業務或挑戰〕正是我想投入的方向」。

原則：誠實但避重就輕（不編理由）、不批評、聚焦有計畫的職涯發展。

**書面自傳只寫第 1、3 步（貢獻 → 拉力），第 2 步「已到一個階段」留給面試口頭說明**（2026-10-12 盲審 v8：「在現有架構下比較難再有大的突破」5／5 輪被判組織負面敘事；書面讀者沒有語氣與表情可以緩衝）。

### 使用者的對照（`library/profile.md` §7）

| 內部真話（不直接寫） | 對外寫法方向 |
| :--- | :--- |
| 多半在舊系統、業務與技術單位之間協調與執行 | 貢獻：舊系統改版、需求窗口、交付成果 → 「這幾年把交付與跨部門流程做穩了」 |
| 產品方針不變的前提下，能做的已經做到 | 階段（**只在面試口頭說**）：「這套系統的改版與流程已經上軌道」；書面省略 |
| 想參與產品方向的決定 | 拉力：「下一步想在更早的階段參與產品方向，從問題定義到成效負責」（**不要寫成現職沒有決定權**） |

已被盲審點名的風險句：「能做的我已經做到」（負面）、「想參與決定要做什麼」（被讀成現職沒有決定權）。

## B. 潤飾成自傳初稿（3c）

- 每篇 essay 濃縮成一段：段落小標＋每段 ≤ 4 行（約 100–150 字），段間空一行，總長 500–800 字。
- 第一句寫結論或處境的關鍵，不用鋪陳。
- 段落之間句型與開頭不重複；不用冒號標籤起頭（例：「定義：」「交付：」）。
- 離職動機段 2–3 句，照三步順序；沒有目標 JD 時不寫 90 天。
- 104 自傳欄不寫姓名、電話、地址。
- 潤飾後**一定接步驟 4（每段 20 版本）與步驟 5 去 AI 感**，再跟履歷一起過 HR、ATS、主管檢測。

## 檢查清單（3c 出口）

- [ ] 每段都對得回一篇 essay，essay 都對得回 library。
- [ ] 沒有重述履歷條列的數字（要用時換角度）。
- [ ] 離職動機：有貢獻 → 階段 → 拉力三步；無 NG 三理由、無批評、無薪資。
- [ ] 事故段有結果；沒有結果的事件已移除。
- [ ] 無家庭背景、興趣、空泛形容；無絕對語氣與組織負面敘事（`scripts/resume_score.py` 旗標 0）。
- [ ] 90 天只在有目標 JD 時出現。
