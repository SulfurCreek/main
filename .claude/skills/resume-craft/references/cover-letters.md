| 需求 | 用什麼 |

| 英文 cover letter | career-ops 的 `cover` 模式（`modes/cover.md`：JD gate、公司研究、語氣校準）；素材取自 `story-bank.md`，優先於 `cv.md`。本 skill 不重做 |
| 中文自我推薦信（推薦函、應徵信） | 本檔＋範本 |

## 中文自我推薦信規格

**A4 一頁、350–500 字、4 段、每段 ≤ 4 行**（手機可讀）。

| 段 | 內容 | 要求 |
| :--- | :--- | :--- |
| ① | 稱謂＋應徵職缺＋一句定位 | 職缺名稱與 JD 一字不差；定位一句話講完 |
| ② | 1–2 個成果證據 | 對應 JD 前三項要求，問題 → 作法 → 結果 |
| ③ | 為什麼是這間公司 | 必須是真實的連結（例如是產品使用者、同領域工作經驗）；寫不出真實連結就縮短這段，不要編 |
| ④ | 前 90 天能做什麼＋面談邀請 | 2–3 件具體事，從 JD 推出；邀請語氣平實 |

**跟自傳的分工**：自傳寫「我是誰」，放 104 自傳欄，通用；推薦信寫「為什麼是這個職缺」，每封客製。兩者不可整段複用。

**台灣語氣**：用「您好」「敬請」等有禮但不卑微的語氣；不寫「懇請給予機會」這類乞求句；不寫家庭背景。

## 硬規則

- 數字只能取自 `career/letters/story-bank.md`；沒有就標 `〔待補數據〕`，不編。
- 寫完存 `career/letters/archive/`，並在 `career/letters/log.md` 加一列。
- career 內容不上 HackMD（`career/CLAUDE.md` 硬規則二）。
- 公司研究只寫查得到的事實，附來源；查不到就不寫那一句。
