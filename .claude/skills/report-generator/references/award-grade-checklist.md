# HTML 報告 award-grade 自我審查清單

使用者要求「以 Awwwards／Webby／FWA 得獎水準為目標」時用這份清單，平常想把 HTML 報告做得更好也適用。
來源：`user-journey/html/MERIT.md` 的 v0→v4 改版，每條都是踩過、修過的實例。

## 1. 審查迴圈（怎麼「自我檢查到滿意」）

1. **先截 v0 當基準，寫出不到標準的具體理由**，不要只寫「不夠好看」。例：第一屏沒有回答這頁在講什麼；篩選器沒承載資訊；同一份資料出現兩次；1440 寬要左右捲。
2. 每一輪都截這幾種情境：
   - 1440 亮色
   - 1440 暗色
   - 390 亮色
   - 互動後的狀態（例如選了一個篩選）
3. 長頁不要只看縮圖。用 `element.screenshot()` 逐段截各 section，原尺寸逐張看。
4. 每輪修完重截，直到「改版前的問題表」每一項都消掉才停。最後跑一次互動測試，確認改版沒弄壞功能。
5. 改動逐條記進專案的 `MERIT.md`，每條都寫「改動＋可重用原則」，能升格的原則回寫進本清單。

Playwright 注意事項：
- 沙盒的 proxy 憑證會擋 Google Fonts，`newPage` 要加 `ignoreHTTPSErrors: true`，才看得到真實字體。
- 固定在頂部的列會出現在 element 截圖裡，那是截圖造成的，不算 bug。

## 2. 設計原則（每條都要能在截圖上指出來）

| 原則 | 判準 | 實例 |
| :--- | :--- | :--- |
| Hero 呈現題目本身 | 第一屏看得到這個題目最有代表性的東西，不是說明表格 | 旅程地圖的 hero＝8 站捷運路線圖 |
| 控制元件帶資訊 | 篩選器本身就是內容（含名稱、狀態、數量），不是另外一排按鈕 | 站點＝階段按鈕，附「頁面 N・文件 N・流程圖 N」 |
| 用題目才有的真實單位 | 至少一個只有這個題目才會出現的細節，而且是內容不是裝飾 | Sitemap 頁面數、新版／現版、支線「任何階段可轉乘」 |
| 同一份資料只呈現一次 | 重複的表格要併掉 | 「階段讀法」表併進路線圖，頁長從 8,800 降到 6,100px |
| 全頁篩選要一直在手邊 | 篩選影響整頁時，離開 hero 後要有固定的迷你版 | 頂部毛玻璃迷你路線列（IntersectionObserver 控制出現） |
| 字體分三種角色 | 標題字、內文字、資料字分開，都有系統 fallback | Archivo 寬體＋Noto Sans TC＋IBM Plex Mono |
| 一個重點色，語意色分開 | 重點色只給主線與互動；語意色（機會點綠、US* 琥珀）不算重點色 | 鈷藍／琥珀／綠 |
| 兩個主題都要設計 | 暗色另外調，不直接反相；中性灰帶重點色的色偏 | 暗底 `#0a0f18`，鈷藍提亮成 `#7390ff` |
| 狀態反映在形式上 | 未啟用時是緊密純文字，啟用才變可點的 chip | Touchpoints：未選時用「・」連成一段文字，選了變錨點 chip |
| 卡片不被撐出空白 | 並排欄位 `align-items:start`；過高的參考資料（術語）改成全寬定義表 | 情境區 |
| 窄螢幕要重新排版 | 860px 以下改直向，不只是縮小 | 路線圖在手機上變直線 |
| 動態只有一個主要時刻 | 一個精心安排的動態，加上 `prefers-reduced-motion` 全關 | 路線畫出 0.9s＋選站脈衝 |
| 空狀態也要設計 | 要有底紋、標題和一句行動指引 | 「先選一個階段」點陣底虛線框 |

## 3. 常見的版面 bug（截圖時逐條找）

| Bug | 修法 |
| :--- | :--- |
| 英文大寫列標在窄欄裡斷字（TOUCHPOI／NTS） | 用窄體、`word-break:keep-all` |
| 兩字元代碼溢出圓圈（6／7） | 縮小字級、`letter-spacing:-0.04em` |
| 寬表在 1440 寬要捲 | 先縮固定欄、外邊距改 `clamp(16px,1.6vw,40px)`，再調欄最小寬 |
| 並排 grid 在手機撐出橫捲 | `grid-template-columns:minmax(0,1fr)`，不要用 `1fr` |
| 大型循序圖 SVG 寬度 100% 時被拉得太高 | 設 `max-width`（約 1180px）置中，小螢幕用 `min-width`＋外層 `overflow-x:auto` |

## 4. 與 §B「自包含鐵律」的關係

字體可以用 Google Fonts（artifact CSP 允許），但條件是漸進增強：每個字體都要有系統字體 fallback，離線開檔仍然完整可讀。除了字體以外，其他外部資源照 §B 第 5 點一律不用。
